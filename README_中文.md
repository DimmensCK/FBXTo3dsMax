把 Maya、Blender 等软件导出的 FBX 数据传入已有的 3ds Max 场景。界面全部中文，保留成熟的两种工作流。本文沿用界面中的名称，数据方向为：

**Max 源模型 ← FBX 目标模型**

这里“Max 源模型”是你在 Max 中选中的接收对象，“FBX 目标模型”是提供数据的 FBX 网格。

## 两种模式

| 模式 | 适用情况 | 结果 |
|---|---|---|
| 模型完全一致 / 传递数据 | 点、边、面和面角可以严格对应 | 保留原 Max 节点，写入勾选的数据 |
| 模型不一致 / 替换并保留蒙皮 | FBX 拓扑已改变，双方都有 Skin | FBX 网格成为最终节点，使用 Max 场景骨架和绑定数据 |

模式一可传递变形/点位置、UV 1/2/3、光滑组、自定义顶点法线、RGB、Alpha、材质及逐面材质 ID。默认只勾选“变形”。相同点数、面数并不够：插件验证顶点身份、边连接、面绕序与面角对应。同向循环起点变化可建立映射；反向绕序或歧义会被阻断。

模式二默认保留 FBX 的网格、UV、材质、顶点色和锁定法线。Max 源 Skin 提供场景骨骼与完整 local data，FBX 提供逐顶点权重、Unnormalized、DQ 与全局 DQ 开关。骨骼名必须能唯一映射，写入后会全量读回。

模式二默认开启“替换时隐藏备份旧网格”，便于回滚；“兼容：改用 Max 源材质”默认关闭。它不复制旧节点的父子层级、变换/动画控制器或任意用户修改器栈。

## 安装与第一次使用

1. 下载或克隆完整仓库；下载 ZIP 时先解压，保持目录结构。
2. 打开 3ds Max，把根目录的 `Install_FBXTo3dsMax.ms` 拖入视口。
3. 安装成功后点击顶部 **FBX 转 MAX** 按钮。
4. 运行 **运行插件自检**，阅读报告。
5. 打开正式场景的副本，先只选一个 Max 源模型。
6. 选择 FBX、模式和需要的通道，点击 **检查 FBX/匹配**。
7. 阅读检查结果，再点击 **开始执行**；最后检查视觉、修改器栈、Skin、动画及保存重载结果。

日常安装直接使用可读 `.ms`、`.py` 和 `.mcr` 源文件。插件使用 Max 自带 Python，不需要另装 Python、编译器或管理员权限。完整安装、重复安装、备份与卸载步骤见 [安装说明](INSTALL_中文.md)。

更换 FBX、模式、所选模型或隐藏对象范围后需要重新检查。只改变传递通道可以直接再次执行；正式执行仍重新导入并验证当前数据。

## 光滑组与法线

光滑组定义相邻面是否共享计算法线；自定义法线保存具体面角方向。

| 选择 | 行为 |
|---|---|
| 只传光滑组 | 保留或严格求解 FBX 的光滑边界，清理插件自己的旧法线修改器 |
| 只传顶点法线，Max 接收端 SG 全为 0 | 完整精确传递 FBX 自定义法线 |
| 只传顶点法线，接收端有非零 SG | 保留现有 SG，写入相对实际 SG 基线超过 `0.1°` 的方向差异 |
| 同时传两者 | 先写入并读回 FBX SG，再执行同一法线差异传递 |

插件保护用户自己的法线修改器；检测到它们会覆盖结果时会停止。不要塌陷或删除结果中的 `F2M_顶点法线`。完整算法与边界见 [使用参考](FBXTo3dsMax_详细说明书.md)。

## 验证范围与限制

本轮真机验收环境为 **Windows 11 x64、3ds Max 2023.3.10、内置 Python 3.9.7**。源码包的 XML 声明 Max 2023–2026；**Max 2024–2026 未验证**，声明范围不等于实测兼容范围。

模式一按对象事务处理，后续对象失败不会自动撤销此前已成功的对象。模式二保留旧网格时支持批次逆序回滚；关闭备份只允许单对象，删除旧网格后存在不可逆边界。第一次正式执行务必使用场景副本。

自检在独立 3ds Max Batch 中运行，不重置当前交互场景。全部项目通过且 Batch 自然退出码为 0 才能成功。正式传递同步执行，当前没有中途安全取消。

自检是一套已知回归测试，不能证明所有未知 BUG 都不存在。开发者验证方法见 [测试说明](docs/TESTING.md)。

## 文件与报告

- 根目录：两种引擎、UI、安装与卸载入口、版本及用户文档。
- `Contents/`：AutoLoader、Macro、工具栏、图标和安装清单。
- `tests/`：维护中的测试代码；几何/蒙皮测试素材由源码在运行时生成。
- `tools/`：公开仓库静态检查和本地 Batch 自检入口。
- `docs/`：测试说明与 [GitHub 发布指南](docs/GITHUB_发布指南.md)。

传递报告、自检与诊断写到 `%LOCALAPPDATA%\FBXTo3dsMax`。安装日志和恢复备份写到 `%APPDATA%\Autodesk\FBXTo3dsMaxInstaller`，不在安装代码旁生成运行报告。

仓库不包含 FBX、MAX 或 BLEND 模型文件。自检使用 `f2m_test_fixtures.py` 提供原创拓扑/原生光滑组数据，并由 `f2m_selfcheck.py` 在 Max 中构建、导出简单两骨骼 Skin 场景；输出到用户本地数据目录。旧加密发行、构建工具链、私有/前雇主资产和本地验证输出不属于公开源码仓库。[更新日志](CHANGELOG_中文.md) 保留简明技术变更；贡献方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
