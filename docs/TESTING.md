# 回归测试与验证边界

正常安装直接使用 Max 自带 Python。开发验证可用 3ds Max 2023 的内置 Python，或已安装的 Python 3.9+ 运行纯测试；真实宿主测试必须使用目标 Max 自带的 `3dsmaxbatch.exe`。

下面命令都在工程根目录执行。`python` 代表你明确选定的解释器；需要指定路径时，在 PowerShell 中使用 `& '<实际 python.exe 路径>'`。

## 1. 仓库静态检查

```powershell
python -B .\tools\check_repository.py
```

检查结构、27 项安装资源、安装器实际“必要目标”与清单一致性、版本同步、公开文件中的秘密/个人路径线索及维护测试的源码依赖。`--json` 输出机器可读结果；`--root` 可指定工程根目录。工具只读文件并向 stdout 输出，不运行安装或 Max。

静态检查通过只证明其检查项；它不证明真实 FBX、Skin 或 UI 正常。

## 2. 纯 Python 回归

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
python -B -m unittest discover -s tests -v
```

覆盖 FBX 元数据解析、拓扑/通道映射、光滑算法、无效输入、源码契约及禁止私有素材入库的检查。测试使用临时目录/原创程序生成数据，无需私有用户模型。仓库中不包含 FBX、MAX 或 BLEND；拓扑数据由 `f2m_test_fixtures.py` 提供，Skin 场景由 `f2m_selfcheck.py` 在 Max 中程序生成并导出；输出到用户本地数据目录。参数 `-B` 避免生成 `.pyc` 缓存。

纯测试和 Python 编译不能替代真实 Max 验证。

## 3. 独立 3ds Max Batch 自检

先保存并关闭所有 Max/Batch，再用 PowerShell 7 运行：

```powershell
pwsh -NoLogo -NoProfile -File .\tools\run_selfcheck.ps1 -MaxBatchExecutable '<实际 Max 安装目录>\3dsmaxbatch.exe' -TimeoutSeconds 900
```

将占位路径替换为存在的绝对路径。启动器拒绝已有 Max/Batch，不会关闭用户进程；它不安装或卸载插件，只从当前源码调用独立自检。

输出放到：

```text
%LOCALAPPDATA%\FBXTo3dsMax\Validation\selfcheck_<UTC时间>_<唯一标识>
```

结果、进度、监听器、stdout/stderr、专用进程日志和 `validation.json` 保存在本次目录，避免旧结果混入。成功要求六类自检全部通过、专用 Batch 自然退出码为 0、对应 Max 日志可核对且原生严重错误为 0、生产源码哈希不变。超时、强制停止、非零退出或只有绿色 JSON 都不能算通过。

这六类包括文件/版本与加载来源、纯光滑算法、Max 过程网格和栈、法线空间/保护/回滚、原创合成 FBX 同拓扑链路、原创合成 FBX Skin 替换链路。拓扑样本为简单三角面并包含 UV/自定义法线/原生 SG；Skin 样本为简单盒子、两根骨骼和非零权重，生成时导出器设置也须恢复。Skin 门检查两种提交、全量权重与绑定/DQ 读回及保存重载。

这些小样本不继承历史私有大模型、数千顶点/几十骨骼或性能压力覆盖，也不证明所有真实资产、Max 版本或未知缺陷都被覆盖。退役私有模型实验仅保留必要代码依赖，不属于可运行的公开素材门。

也可以从已安装插件点击“运行插件自检”。已安装副本会额外验证安装 manifest；报告在 `%LOCALAPPDATA%\FBXTo3dsMax\SelfCheck`。

## 4. 安装和用户流程验收

在独立测试配置或可恢复副本中，从完整源码运行标准 `.ms` 安装入口，验证：

- 全新安装、同版本重复安装及版本/27 项 SHA-256 清单读回。
- 独占锁、所有权冲突、安全归档、运行模块与三 Helper 清理。
- 新进程冷启动、唯一可见可点击的中文按钮、主窗口打开。
- 安装副本自检、两种模式、选择/名称/Importer 设置与临时节点恢复。
- 相关安装器改动的失败回滚及可恢复卸载；保留恢复归档。

真实项目的首轮使用在场景副本上进行。模式一逐对象提交，模式二保留旧网格时才有批次回滚；删除式提交不能作无损恢复承诺。还需核对视觉、动画与保存重载。

这些宿主验收要求专用进程自然退出 **0**、所查原生严重错误 **0**、生产源码哈希不变；首次启动保留完整原始日志；后续同配置启动验证完整启动前前缀 SHA、追加字节与新进程身份/时间窗口，不能以旧报告、强制结束或仅 JSON 成功替代。

UI 验收调用真实 `QToolButton.click` 信号路径，并检查界面确实打开；它不是物理鼠标点击记录。回滚证明仅覆盖上述单处安装后激活失败，不能代表所有故障点。卸载证明完整可恢复归档的内容与哈希，**没有执行从该卸载归档重新恢复安装**。

XML 声明 Max 2023–2026，**Max 2024–2026 未验证**。小型生成样本不覆盖复杂生产资产、大模型压力或所有未知缺陷。首次使用仍应在场景副本上核对视觉、动画与保存重载。原始本机日志、运行身份、私有工具和资产不提交公开仓库。
